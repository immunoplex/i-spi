This screen manages descriptive metadata for one experiment at a time, in three
groups: **Analytes** (antigen and feature facts — source, strain, catalog/lot
number, reagent acquisition date, family), **Sample Levels** (the distinct
timepoint and arm/group values seen in this experiment's data, with a short
description for each and an optional **referent** level — the baseline/reference
value for that variable), and **Display Order** (drag-to-reorder the antigen,
feature, timepoint, and arm/group lists wherever they're shown elsewhere in the
app).

Pick an experiment, edit the relevant grid, and **Save** each section separately —
saving one section doesn't save the others.
