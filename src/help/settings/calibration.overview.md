Settings here apply at a **scope** — Project, Study, and (where applicable) a
narrower Experiment, Feature, or Antigen — shown as a breadcrumb at the top of
this screen. A narrower scope **inherits** every setting from the broader scopes
above it unless you override it at that narrower level; the **Set here / inherited**
label next to each value shows which is happening, and a **revert** link appears
only on a value you've actually overridden at the scope you're currently viewing.

Each row shows the setting's current effective value and a short one-line
description; many rows also carry a small info icon next to the label with a
deeper explanation of that specific setting — this screen is about how the editor
itself works, not what each individual setting does.

::: more
Switching the breadcrumb to a narrower scope (an experiment, then a feature, then
an antigen) is optional and only appears when that scope actually has more than one
value to choose from in this study — with only one experiment, for example, the
Experiment tier is skipped automatically rather than shown as a pointless choice of
one.
:::
