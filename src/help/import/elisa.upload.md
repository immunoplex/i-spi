title: Importing ELISA plate files
audience: user
category: procedural
see_also: [import.plate_grid.confirm, compute.import.description_shape_binding]
---
Select one or more ELISA plate files and click **Parse uploaded file(s)** — there
are no extra controls to set for this format; the feature (analyte) is read
directly from the plate map sheet in the file. From there, continue through
[[import.plate_grid.confirm|confirming the plate layout]] and
[[compute.import.description_shape_binding|configuring the description field]].
