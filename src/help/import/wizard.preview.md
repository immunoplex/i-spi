A quick sanity check before committing: one row per sheet in the uploaded
workbook, with its row count. Use it to confirm every sheet you expected to
have data actually does — a sheet showing 0 rows when you expected content is
worth investigating before you [[import.wizard.commit|commit]], even if
validation reported no errors.
