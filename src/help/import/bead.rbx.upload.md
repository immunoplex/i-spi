id: import.bead.rbx.upload
title: Importing Bio-Plex (.rbx/.srbx) files
audience: user
category: procedural
see_also: [import.plate_grid.confirm, compute.import.description_shape_binding]
---
Select one or more Bio-Plex `.rbx`/`.srbx` files, enter the **Feature** (the isotype
being measured, e.g. `IgG`, 15 characters or fewer), and click **Parse uploaded
file(s)**. Plate size is read from the file itself — there's nothing to set. Once
parsed, continue through [[import.plate_grid.confirm|confirming the plate layout]]
and [[compute.import.description_shape_binding|configuring the description field]]
before downloading the layout template.
