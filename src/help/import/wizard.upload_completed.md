Upload the workbook you downloaded and (optionally) edited in the previous step.
I-SPI parses it and runs [[import.wizard.validation|validation]] immediately on
upload — there's no separate "check" button, so the **Validation** and **Preview**
sections below update as soon as the file finishes uploading. If you need to make
another change, just edit the workbook again and re-upload it; each upload
replaces the previous one.
