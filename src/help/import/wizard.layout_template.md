Once the layout and description rules are confirmed above, download the **layout
template** — a workbook pre-filled from everything you just set up (specimen
types, descriptions, dilutions). Open it and check it over; it stays fully
editable by design, so this is also where you can make a correction by hand
before anything is written to the database. When it looks right, continue to
[[import.wizard.upload_completed|uploading the completed template]].
