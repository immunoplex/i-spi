Select one or more Raw File `.xlsx` workbooks and click **Parse uploaded file(s)**.
This is the plain spreadsheet format — use it when you have a manually assembled
or instrument-export-converted workbook rather than a native Bio-Plex or xPONENT
export. As with xPONENT, this format carries no instrument-reported dilution
value, so Standards wells typically need a manual dilution reference during
[[import.plate_grid.confirm|confirming the plate layout]]. Continue through
[[compute.import.description_shape_binding|configuring the description field]] as
usual from there.
