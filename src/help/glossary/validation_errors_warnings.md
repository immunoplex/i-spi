id: glossary.validation_errors_warnings
title: Validation errors vs. warnings
audience: user
category: glossary
---
A validation **error** means something is missing or wrong that would make the
data unusable (e.g. a required sheet or column is absent) — it **blocks commit**
until fixed. A **warning** flags something worth a second look (e.g. an unusual
but not invalid value) but doesn't block commit — you can proceed with warnings
present if you've reviewed them.
